# Установка Bench

Три способа — выбирайте под себя. Приложению не нужны никакие зависимости, кроме
Python 3 (а для `.exe` не нужен и он).

---

## 1. Скрипты-лаунчеры (кросс-платформа, рекомендуется)

Нужен **Python 3.8+**. Скачайте репозиторий (кнопка **Code → Download ZIP** на
GitHub или `git clone`), распакуйте и:

### Windows
- Двойной клик по **`run.bat`** — откроется `http://localhost:8791`.
- Или разово настроить ярлык на рабочем столе:
  ```powershell
  powershell -ExecutionPolicy Bypass -File install.ps1
  ```

### macOS / Linux
```bash
./install.sh     # проверит Python и (на Linux) добавит ярлык
./run.sh         # запуск; откроется http://localhost:8791
```

Планы сохраняются на диск в папку `projects/` рядом с приложением и переживают
перезагрузку.

---

## 2. Windows `.exe` (один клик, без Python)

Готовый `Bench.exe` лежит в разделе **Releases** репозитория (собирается
автоматически из исходников через GitHub Actions).

1. Скачайте `Bench.exe`.
2. Положите в любую папку и запустите двойным кликом.
3. Откроется `http://localhost:8791`. Планы сохранятся в папку `projects\` рядом
   с `.exe`.

Собрать `.exe` самостоятельно:
```powershell
powershell -ExecutionPolicy Bypass -File build_exe.ps1   # → dist\Bench.exe
```

---

## 3. Docker (любая ОС, изолированно)

Нужен Docker Desktop / Docker Engine.

```bash
docker compose up --build
```

Откройте `http://localhost:8791`. Планы хранятся в примонтированной папке
`./projects` и переживают пересборку контейнера. Порты проброшены только на
loopback хоста (`127.0.0.1`) — приложение не торчит в сеть.

---

## Порты

| Порт | Зачем |
|---|---|
| 8791 | интерфейс конструктора + сохранение планов (`/api`) |
| 8792 | прокси ИИ-чата (обход CORS к LLM-провайдеру) |

Переопределяются переменными `TESTER_PORT` и `TESTER_PROXY_PORT`.
Авто-открытие браузера отключается `TESTER_OPEN=0`.

Дальше — как подключить свой API и работать через ИИ-агента, см. [README](README.md)
раздел «ИИ-агент и MCP».
