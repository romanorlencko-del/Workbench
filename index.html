Проработать проект по чек-листу?

Список того, что стоит решить до кода: рамки, данные, ИИ-ядро, интерфейсы, надёжность, выпуск. Отметьте нужное — и агент будет видеть, что ещё не проработано. Можно пропустить и вернуться в любой момент: вкладка Чек-лист в консоли.

Сначала профиль — от него зависит, половина пунктов вам нужна или нет:
✦ ИИ · как дорабатывать план
  • Узел = шаг (его параметры — ТЗ шага), ребро = связь. Порядок по потоку = порядок сборки.
  • Порты двух видов: flow (сплошная — порядок выполнения) и data (пунктир — знания/контекст). Соединять можно только одинаковые.
  • Правка экономно: меняй минимум → верни весь план минифицированным JSON → кнопка Импорт (↥). id держи стабильными, meta.rev +1, затем ⌗ разложит.
  • Полный каталог блоков и схема JSON — файл AI_GUIDE.md в проекте (и в разделе «Бриф»).

Сжатые правила + текущий план минифицированным JSON. Вставь в Hermes-агента или локальный ИИ — он вернёт обновлённый JSON, ты импортируешь через ↥.
