Рабочая папка проекта Bench `p_mvgh3n98tlp` (план: `../../projects/p_mvgh3n98tlp.json`).
Дашборд: https://claude.ai/artifact/6gJVkczyWaovoJUXbKnuzV

Состояние на 2026-10-20: в дашборде 34 семейства материалов, граф «элементы ↔ семейства»,
лестницы «теория → известно → применяется» и, с этого дня, агрегатные состояния при нагреве (1 атм).

## Достоверность агрегатных состояний

Ни одно число в `phase_states.json` не сверено с открытой страницей: в облачном окружении
справочные сайты были закрыты сетевой политикой. Колонка `conf`:

- `сниппет поиска` — число из выдачи веб-поиска; `source` — страница, откуда пришёл сниппет (сама не открывалась);
- `по памяти` — справочное значение, вписанное при сверке, или поправка к ответу агента.

Обязательно подтвердить: ВЭС (сплав Кантора 1280–1340 °C), NiTi, SmCo5, PZT, LaMnO3, сплавы 7075 и 430,
Waspaloy, CMSX-4, периклаз и торианит в «Минералах», ликвидус чугуна.

## Пересчёт по таблице Менделеева и физическим законам

`python3 scripts/recalc.py --apply` (нужен `pip install -r requirements.txt`) локально, без сети, сверяет данные
с двумя базами элементов — пакетом `mendeleev` и таблицей pymatgen-core (`vendor/`) — и с законами:

| Проверка | Закон или источник |
| --- | --- |
| C(80,k) в «Масштабе», 80 стабильных и 118 элементов, C(50,5) у ВЭС, сумма у минералов | сочетания; изотопы без распада с природной распространённостью |
| применяется ≤ известно ≤ теоретически | подмножество не больше множества |
| тип элемента | серия в таблице Менделеева |
| формулы членов семейства ⊆ его элементы; молярные массы и массовые доли | закон постоянства состава |
| T плавления и кипения чистых элементов и основ сплавов | обе базы, допуск ±1 % по шкале Кельвина |
| солидус < Tпл основы; ликвидус ≤ Tпл основы, кроме изоморфных систем (Cu–Ni) | диаграммы состояния |
| солидус чугуна, нижняя граница припоев | эвтектики Fe–C 1147…1153 °C и Sn–Bi 139 °C (константы по памяти) |
| ΔS испарения и плавления | правила Трутона и Ричардса |
| порядок температур, состояние при 25 °C, числа в тексте пути | согласованность фаз |

Цикл: проход повторяется, пока что-то исправляет. Само исправляется только точное — комбинаторика,
арифметика, формула ↔ элементы, а также температуры, где обе базы сходятся, а наша вне допуска.
Первый прогон (2026-10-20): 2 исправления (Mn в перовскитах — из LaMnO₃; кипение Al 2470 → 2519 °C),
затем 0. Осталось на разбор 3 предупреждения: H₃PO₄ в подписи фосфора (продукт, не член семейства),
солидус чугуна 1140 °C ниже эвтектики Fe–C, в тексте пути SiC нет числа 2730. Отчёт — `data/checks/recalc_report.md`,
молярные массы — `data/derived.json`. В плане Bench это блоки «Цикл пересчёта» → «Пересчёт…» → «Остались ошибки?».

## Достоверность применения и названий

Тот же прогон без доступа к страницам: 29 строк — `сниппет поиска` (подтверждено хотя бы
название или стандарт; примеры применения частично по памяти), 5 — `по памяти` (исправлены при сверке).
Сверить с действующими редакциями: ГОСТ 28818, 9808, 4543, 1412, 7293, 19807, 2856; соответствия
марок (АД31 ↔ 6063, В95 ↔ 7075, 316 ↔ 03Х17Н14М3, ХН45МВТЮБР ↔ Inconel 718).

## Как дорабатывать

1. **Перепроверка.** Открыть домены en/ru.wikipedia.org, webbook.nist.gov, pubchem.ncbi.nlm.nih.gov
   и перезапустить агентов по `agents/README.md`; ответы положить в `data/raw`.
2. **Сборка.** `python3 scripts/build_states.py data/raw data/phase_states.json` (запуск из этой папки).
   Ручные правки (`ov(...)`) убирать по мере того, как появляются подтверждённые числа.
3. **Публикация.** Загрузить новый `phase_states.json` в ассеты дашборда и обновить у датасета
   `states` поля `source.url`, `source.name`, `updated`. Страницу менять в `dashboard/index.html`
   и записывать целиком в `files/index.html`.
4. **План в Bench.** `python3 ../../serve.py`, открыть http://localhost:8791, включить «Сопряжение»
   (✦ ИИ → MCP). Дальше правки — только через MCP: сервер `bench` прописан в корневом `.mcp.json`
   (Claude Code подхватит его при старте сессии), либо `python3 scripts/mcp_call.py get_plan apply_ops <ops.json>`.
   Держите открытым один экземпляр конструктора: второй сохранит план поверх, и движок отобьёт запись (409).
