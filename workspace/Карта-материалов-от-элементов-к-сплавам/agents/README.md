Сырые ответы лежат в `../data/raw/batch1..6.json`, сводный результат — в `../data/phase_states.json`.

## Общий промпт

Для каждой партии: список `id — русское название — элементы` плюс подсказки по семейству
(какие марки или формы брать, известные особенности: сублимация графита, разложение SiC,
стеклование у стекла и т. п.).

Каждый материал — один JSON-объект с ключами:

- `id` — id семейства
- `state_25C` — «твёрдое», «жидкое» или «газ» при 25 °C и 1 атм
- `melt_low_C`, `melt_high_C` — солидус и ликвидус, либо диапазон точек плавления по семейству, °C
- `boil_C` — кипение при 1 атм, °C (null, если разлагается или неизвестно)
- `decomp_C` — разложение или сублимация вместо плавления или кипения, °C
- `liquid_exists` — есть ли жидкая фаза при 1 атм
- `heating_path` — короткая строка, например «твёрдое → жидкое (1538 °C) → газ (2862 °C)»
- `note` — одно предложение: что меняется внутри семейства
- `conf` — «справочно» или «оценка»
- `source` — URL открытой страницы

Числа округляются до целых °C. Числа не выдумывать: если не найдено — null и пояснение в `note`.
Результат — JSON-массив, записанный в `states/batchN.json`.

## Что пошло не так в первом прогоне

Сетевая политика облачного окружения закрыла справочные сайты: en/ru.wikipedia.org,
webbook.nist.gov, pubchem, matweb и другие, даже example.com. Агенты видели только
сниппеты веб-поиска. Поэтому:

- партия 2 вернула только состояния, все числа пустые;
- партия 6 вернула числа из подсказок промпта без ссылок;
- остальные взяли числа из сниппетов; ссылка в `source` — страница, откуда пришёл сниппет, сама она не открывалась.

Перед следующим прогоном откройте эти домены в настройках окружения (Network access → Allowed domains).
